# Техническое задание (черновик)
## Система автоматического управления узлом горячей воды для моечной линии

Составил: Артём Смирнов. Источник — только ответы главного механика (Виктор Андреевич).

### 1. Назначение и цели
- Цель: стабильная подача горячей воды на моечную линию; температура и давление не должны «гулять».
- Сейчас (есть): оператор регулирует всё вручную.
- Требуется: температура и давление должны поддерживаться автоматически.

### 2. Объект автоматизации
- Есть сейчас: пластинчатый теплообменник, насос, линия на мойку. Вода греется теплоносителем в теплообменнике, насос подаёт её на мойку.
- Двигатель насоса — 2,2 кВт.
- Полный перечень установленных приборов, арматуры и приводов — НЕ ВЫЯСНЕНО (требует обследования объекта).
- Как сейчас управляют насосом — НЕ ВЫЯСНЕНО (требует обследования объекта).
- Теплоноситель: на подаче около 95 °C ±5, давление около 0,6 МПа.

### 3. Контролируемые параметры
| Параметр | Значение |
|---|---|
| Температура воды после теплообменника | норма 60 °C |
| Давление воды до насоса (вход) | обычно 0,15–0,25 МПа, зависит от водопровода |
| Давление воды после насоса | норма 0,30 МПа |
| Расход воды | рабочий 1,5–4 м³/ч, больше ~4 м³/ч не бывает |
| Температура / давление теплоносителя | ~95 ±5 °C / ~0,6 МПа (контролировать ли — НЕ ВЫЯСНЕНО) |
- Места установки датчиков — НЕ ВЫЯСНЕНО.
- Тип и производитель датчиков — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать (с обоснованием).

### 4. Регулируемые параметры
- Температура воды на мойку: 60 °C, допустимо ±2 °C.
- Давление после насоса: 0,30 МПа, допустимо 0,27–0,33 МПа.
- Регулирование температуры — плавное, без режима «открыт-закрыт».
- Оператор может менять уставки температуры и давления; опасное значение задать должно быть нельзя.
- Допустимые пределы изменения уставок — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.

### 5. Режимы работы
- Режимы: автоматический, ручной, обслуживание.
- Обслуживание: отдельная проверка механизмов (прокрутка насоса, перемещение клапана).
- Ручной режим обязателен; порядок работы в нём — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.
- Защиты действуют во всех режимах, в т.ч. в ручном.
- Кто и как переключает режимы — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.
- Пуск после аварии: выяснить причину → устранить → подтвердить сброс → только потом пуск. После серьёзной аварии автоматический запуск запрещён.

### 6. Предупредительная сигнализация
- Температура воды 70 °C — предупреждение оператору.
- Давление после насоса 0,40 МПа — предупреждение оператору.
- Предупреждение по низкой температуре воды — НЕ ВЫЯСНЕНО.

### 7. Аварийные защиты
| Условие | Действие |
|---|---|
| Температура воды 75 °C | прекратить нагрев, не подавать перегретую воду на мойку |
| Давление после насоса 0,45 МПа | остановить насос |
| Давление на входе работающего насоса < 0,08 МПа | остановить насос |
| Расход < 0,8 м³/ч (нет протока) | запретить нагрев |
| Потеря питания | клапан теплоносителя закрывается |
- Низкое давление после насоса: порог и реакция — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.
- Отказ насоса или ПЧ: реакция — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.
- Кнопка аварийного останова — не обсуждалась; если нужна — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.
- Отказ датчика — НЕ ВЫЯСНЕНО (был ответ «клапан закрываем и сигналим аварию», но я не понял, к какому вопросу он относится).

### 8. Исполнительные устройства
- Насос — управление через преобразователь частоты; прямой пуск не допускается.
- Регулирующий клапан на теплоносителе: регулирование плавное; при потере питания — закрыт.
- Тип клапана и привода — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ.

### 9. Операторский интерфейс
- На основном экране: температура после теплообменника, давление до и после насоса, расход, состояние насоса, авария насоса, положение клапана, текущий режим.
- Тип панели и место установки — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.
- Журнал аварий — обязателен. Срок хранения — ПРЕДЛАГАЕТ ИСПОЛНИТЕЛЬ / согласовать.

### 10. Электропитание
