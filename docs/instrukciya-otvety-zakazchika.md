# Как настроить ответы заказчика

Эта инструкция для преподавателя. Программировать не нужно: все ответы заказчика лежат в одном файле JSON. Его можно поправить в любом текстовом редакторе или с помощью ChatGPT, а потом загрузить на сайт и сразу проверить.

## Коротко

1. Откройте сайт и нажмите **«Ответы заказчика (тест)»**: на стартовом экране — внизу формы, во время диалога — в меню «⋯».
2. Нажмите **«Скачать текущие ответы»**. Скачается файл `otvety-zakazchika.json` со всеми темами, вопросами и ответами. Он же лежит в папке проекта: `docs/otvety-zakazchika.json`.
3. Поправьте ответы вручную или через ChatGPT (промпт ниже).
4. Нажмите **«Загрузить файл ответов»** и выберите исправленный файл. Если в нём ошибка, сайт напишет, какая и где.
5. Проверьте ответы: напишите вопросы в поле **«Проверка вопросов»**, по одному на строку, и нажмите **«Проверить»**. Результат можно скачать таблицей для Excel. Можно и просто начать диалог — заказчик уже отвечает по-новому.
6. Не понравилось — **«Вернуть исходные»**.

Загруженный файл действует только в вашем браузере. Студенты на своих компьютерах видят исходные ответы. Когда ответы устроят, пришлите итоговый файл разработчику: он встроит их в сайт для всех.

## Как устроен файл

Одна тема — один блок:

```json
{
  "id": "temp_setpoint",
  "title": "Рабочая температура",
  "note": "сведения об объекте",
  "facts": ["Рабочая температура после теплообменника: 60 °C."],
  "questions": [
    "Какая температура воды нужна после теплообменника?",
    "До какой температуры нагревать воду?"
  ],
  "replies": [
    "Обычно нам нужно около 60 градусов.",
    "Нормально, когда после теплообменника выходит 60 градусов."
  ],
  "repeat": ["60 градусов."]
}
```

| Поле | Что это | Можно менять? |
|---|---|---|
| `id` | Служебное имя темы | Нет. По нему ответ привязан к теме и к оценке |
| `title`, `note` | Название и пояснение для вас | Не обязательно, на работу не влияют |
| `facts` | Какие сведения должен сообщить ответ | Только для справки, при загрузке не читается |
| `questions` | Как студенты могут спросить | Да. Добавленные вопросы распознаются в первую очередь |
| `replies` | Варианты ответа. Заказчик выбирает один и не повторяет его подряд | Да |
| `steps` | Ответ по частям вместо `replies`: шаг 1 — на первый вопрос, шаг 2 — на «что ещё?» и так далее | Да, но число шагов менять нельзя |
| `repeat` | Короткий ответ, если студент спросил то же ещё раз | Да |

В начале файла есть ещё три поля:

- `greeting` — первая реплика заказчика в начале диалога.
- `fallback` — ответы, когда заказчик не понял вопрос.
- `clarifications` — встречные вопросы на неоднозначный вопрос. Например, `pressure` задаётся, когда студент спросил «какое давление?» и не сказал где.

### Как добавить новую тему

Добавьте в список `answers` блок без `id`:

```json
{
  "title": "Кто обслуживает систему",
  "questions": ["Кто будет обслуживать систему?", "Есть ли у вас наладчики?"],
  "replies": ["Свои наладчики, по двое на смену."]
}
```

Новая тема отвечает на свои вопросы и на близкие формулировки, но в оценку ТЗ не входит.

## Правила для ответов

- **Отвечать только на заданный вопрос.** Одна–три мысли. Не перечислять то, о чём не спрашивали, — студент должен учиться задавать вопросы.
- **Цифры как в `facts`.** Оценка ТЗ сверяет значения с эталоном. Если в ответе окажется другое число, сайт предупредит. Поменять сами цифры можно только в коде — напишите разработчику.
- **Число прописью допустимо** («двух градусов»), но цифрами студенту проще.
- **Темы с пометкой «заказчик не знает»** должны оставаться ответом «не знаю, предложите сами»: так студент учится понимать, что решать будет он.
- **Темы с пометкой «слишком общий вопрос»** не должны давать конкретных значений.
- Сохраняйте кавычки, запятые и квадратные скобки. Если сайт пишет «Файл не читается как JSON», почти всегда пропущена запятая между строками или лишняя запятая после последней.

## Промпт для ChatGPT

Прикрепите файл `otvety-zakazchika.json` и вставьте текст:

> Это файл ответов заказчика для учебного тренажёра. Студент-инженер по автоматизации задаёт вопросы заказчику (главному механику завода) и составляет техническое задание на систему управления узлом горячей воды для моечной линии.
>
> Перепиши поля `replies`, `steps`, `repeat`, `greeting` и `fallback`, чтобы заказчик отвечал естественно и по-человечески: коротко, разговорно, без канцелярита, как занятой механик в переписке.
>
> Строгие правила:
> 1. Не меняй `id`, `title`, `note`, `facts`, `format`, `version`, структуру файла и количество шагов в `steps`.
> 2. В каждом ответе сохрани ровно те значения и единицы, что указаны в `facts` этой темы. Не добавляй новых чисел и сведений.
> 3. Отвечай только на то, о чём спросили: одна–три мысли, без перечисления остального.
> 4. Где `note` равно «заказчик не знает…», заказчик должен честно не знать и предлагать инженеру решить самому.
> 5. Где `note` равно «слишком общий вопрос…», не давай конкретных значений, проси спрашивать по отдельным параметрам.
> 6. Для каждой темы дай 3 разных варианта `replies`, а не одну фразу с заменой слова.
> 7. В `questions` добавь по 3–5 новых формулировок, как реально пишут студенты, включая короткие и с ошибками.
>
> Верни полный файл JSON целиком, без пояснений.

Если файл большой и ChatGPT обрывает ответ, попросите обработать его частями: «первые 30 тем», «следующие 30» — и соберите их в один список `answers`.
